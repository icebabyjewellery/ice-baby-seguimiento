# Seguimiento Ice Baby (mod de Claude)

Mod del equipo de Ice Baby. A la vista: avisa al abrir Claude de que está activo
y manda al panel qué haces en Claude (abrir/cerrar, un latido cada 5 min y cuándo
tocas archivos). No lee el contenido de los archivos ni mira nada fuera de Claude.

## Instalar (una vez)

En tu terminal de Claude, pega:

```
/plugin install ib-seguimiento --marketplace icebabyjewellery/ice-baby-seguimiento
```

Responde `y` para añadir el marketplace y elige el ámbito de usuario.
Luego te pedirá dos datos:
- **usuario**: tu nombre en el panel (kenneth, elva, juan o sergio).
- **token**: el que te da Ivo.
